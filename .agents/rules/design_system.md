# Guía de Identidad Visual — Sistemas de Gestión Deportiva (Proscom Soluciones)

Guía de identidad visual reutilizable para cualquier sistema de gestión deportiva de Proscom Soluciones.

---

## Directrices de Diseño

- **Color primario:** verde esmeralda `emerald-600` (#059669), con degradado hacia `teal-600` (#0d9488) en botones principales, logo y elementos destacados.
- **Neutros:** escala `slate` de Tailwind — fondo general en `slate-50` (#f8fafc), tarjetas en blanco, texto principal en `slate-900` (#0f172a), texto secundario en `slate-500`/`slate-400`.
- **Colores semánticos:**
  - Verde esmeralda (`emerald-600`): Positivo / ingresos / al día / confirmado / éxito.
  - Rojo/Rosa (`rose-600` / `#e11d48`): Negativo / egresos / error / eliminar / atrasado.
  - Ámbar (`amber-600` / `#d97706`): Alertas / pendientes / advertencias.
  - Azul (`blue-600` / `#2563eb`) e Índigo (`indigo-600` / `#4f46e5`): Categorías informativas, acciones secundarias o de edición.
  - Púrpura (`purple-600` / `#9333ea`): Inscripciones o categorías especiales.
- **Regla del color semántico:** El color semántico SIEMPRE tiene prioridad sobre el color de marca (Verde = bien, Rojo = mal).
- **Tipografía:** `Figtree` (Google Font) como fuente principal con respaldo sans-serif. Peso tipográfico alto (`font-extrabold`/`font-black` en títulos y cifras importantes) para transmitir solidez y confianza.
- **Forma y sombras:** Esquinas muy redondeadas (`rounded-xl` a `rounded-2xl`/`rounded-3xl`), tarjetas blancas sobre fondo gris muy claro, sombras suaves y difusas coloreadas con el tono del elemento (nunca sombra gris genérica), bordes sutiles (`slate-200`).
- **Iconografía:** Emojis nativos en vez de librerías SVG de íconos para un tono cercano y humano, manteniendo seriedad institucional.
- **Tono general:** Confiable e institucional pero cercano, estilo fintech seria.
